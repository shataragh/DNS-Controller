## 📖 About

DNS Controller is a comprehensive Python-based tool designed to optimize DNS resolution, enhance security, and improve internet connectivity through intelligent DNS management. The tool automatically selects the best-performing, most secure DNS servers and routes all internet traffic through optimized pathways.

**Key Benefits:**
- ⚡ **Performance Optimization** - Automatically selects fastest DNS servers
- 🛡️ **Security Enhancement** - Includes malware and ad-blocking DNS options  
- 🔄 **Auto-Restore** - Safely restores original DNS settings on exit
- 🌍 **Global Coverage** - Optimized DNS for different regions worldwide
- 📊 **Analytics** - Performance monitoring and analysis

## 🚀 Features

### Core Features
- **DNS Management**: Change DNS settings across Windows, Linux, and macOS
- **Auto-Restore**: Automatically restores original DNS settings on exit
- **Performance Testing**: Comprehensive DNS resolution and latency testing
- **Real-time Monitoring**: Monitors DNS changes and provides alerts

### Advanced Features
- **Performance Analytics**: Tests and ranks DNS servers by speed and stability
- **Regional Optimization**: Optimized DNS servers for different continents
- **Security Options**: Includes malware, ad, and adult content blocking DNS
- **Comprehensive Testing**: Tests access to 10+ popular websites
- **User-Friendly Interface**: Color-coded menu system with emoji indicators

### DNS Categories
- **Global Optimized**: Cloudflare, Google, Quad9, OpenDNS
- **Security Focused**: AdGuard, Quad9 Enhanced, OpenDNS Security
- **Regional**: Optimized for 6+ continents
- **Privacy**: Ad-blocking and content filtering options
